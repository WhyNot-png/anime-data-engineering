# Отчёт по лабораторной работе 1

## Проект и уровень

Anime Data Engineering — каркас проекта обработки снимка MyAnimeList.
Основной источник: [Anime Database (July 2025)](https://www.kaggle.com/datasets/sazzadsiddiquelikhon/myanimelist-anime-database-july-2025).
Наличие публичного набора подтверждено API каталога Kaggle; реальные данные
не скачивались. Согласно метаданным источника, набор содержит более 28 тысяч тайтлов.

Реализован **базовый+ (С1–С10)**. Дополнительно выбраны **П1** — матрица
Python 3.12.12/3.13.9 × Ubuntu/Windows и **П3** — структурное JSON-логирование
с переключением через `RG_LOG_FORMAT` и тестами корректности формата.
Проверки матрицы выполняются реальными GitHub-hosted раннерами;
локальный Linux-прогон не подменяет проверку Windows.

## Реализация и проверки

Зависимости и версии зафиксированы в `pyproject.toml`, `uv.lock` и `.python-version`.
Пакет `research_graph` устанавливается из `src/research_graph`; точка входа
`rg` предоставляет `version` и `check-config`. `Settings` читает `RG_*` и `.env`,
проверяет числовые границы и не печатает токен. Логи идут в stderr,
stdout остаётся пригодным для JSON-сводки. Повторная инициализация логирования
не дублирует обработчики. Есть заготовки `models`, `sources`, `storage`, `pipelines`, `api`.

Локально на Python 3.12.12 прошли ruff, форматирование, strict mypy, pre-commit,
сборка wheel/sdist и **36 тестов**; branch coverage — **91,33%** при обязательном
пороге 70%. Тесты изолируют окружение и `.env`, проверяют скрытие токена,
JSON/text-логи и локальный цикл CSV → Parquet → SQLite без сети и учётных данных.
Workflow повторяет проверки в четырёх комбинациях ОС/Python, фиксирует actions
по SHA и uv по версии. Актуальный результат доступен в
[GitHub Actions](https://github.com/WhyNot-png/anime-data-engineering/actions).

## Затруднения и решения

- Старый `src/__init__.py` превращал `src` в пакет: mypy находил один модуль
  под двумя именами. Маркер удалён, настроены explicit package bases и `mypy_path=src`.
- При проверке только CLI покрытие всего сохранённого пакета было 61,33%.
  Вместо исключения ETL из coverage добавлены содержательные интеграционные
  тесты преобразования/загрузки и тест оркестрации с подменой сетевого источника.
- Веб-загрузчик карточки Kaggle вернул 404, но публичный API каталога подтвердил
  существование и публичность точного идентификатора. Источник не заменялся догадкой.

## Отличия от образца

Репозиторий уже содержал ETL с pandas/Parquet/SQLAlchemy. Чтобы не потерять работу,
он перенесён внутрь устанавливаемого пакета; старые модули оставлены тонкими
совместимыми обёртками. Тяжёлые зависимости вынесены в extra `etl`, а библиотеки
для локальных интеграционных тестов — в dev-группу. Базовые runtime-зависимости
ограничены pydantic, pydantic-settings и typer. Глобального отключения mypy нет:
исключения импорта точечные для необязательных Kaggle/SQLAlchemy.

Тег `lab1` следует ставить на окончательный проверенный коммит после включения
изменений в `main`. Подготовка PR сама по себе не означает, что тег уже опубликован.
