# Результаты, которые можно пересобрать

**Задание 3 · Генераторы статических сайтов · T1 + P3**

Этот сайт продолжает проект Anime Data Engineering: данные MyAnimeList превращаются
в проверяемые агрегаты, таблицы и график. Исходный код, параметры, числовой снимок
и метки версии доступны независимо от оформления сайта.

- [T1: сравнение MkDocs Material, Sphinx + MyST, Pelican и Nikola](t1.md).

- [Результаты расчёта и сведения о версии](results.md).
